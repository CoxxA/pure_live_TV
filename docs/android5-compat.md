# 纯粹直播 TV（安卓5兼容版）使用说明

交付版本：**v3.0.7-android5.3+1003，预览版**。基于上游 v3.0.7，源码在 [CoxxA/pure_live_TV](https://github.com/CoxxA/pure_live_TV/tree/android5-compat)。

## 安装到这台电视

小米 L55M4-AA 的系统实际报告为 **Android 5.1.1、32 位 ARM**，请安装发布页的：

**[PureLive-TV-android5-armeabi-v7a-skia.apk](https://github.com/CoxxA/pure_live_TV/releases/download/v3.0.7-android5.3/PureLive-TV-android5-armeabi-v7a-skia.apk)**

也可从 [第三版发布页](https://github.com/CoxxA/pure_live_TV/releases/tag/v3.0.7-android5.3) 下载，用 U 盘安装或通过已开启的 ADB 安装。`arm64-v8a` 包供其他 64 位 Android 系统使用，本电视应选 32 位包。需要核对文件时，使用发布页的 [SHA256SUMS](https://github.com/CoxxA/pure_live_TV/releases/download/v3.0.7-android5.3/SHA256SUMS)。

电视已用本目录对应的 GitHub 正式发布 ARM32 APK 覆盖安装，版本代码 1003，启动成功，原兼容版收藏保留。

## 推荐播放设置

- 内核选 **MPV**，开启 **兼容模式**，保持 **硬件解码开启**。
- 优先选择 **720P**；如需降低负荷，可关闭弹幕。
- 机主已确认该模式音画同步，仍有轻微掉帧，原先的旧版也有类似表现。
- **IJK 暂作备用**：第二版关闭额外截图渲染后卡顿改善，但本电视仍有音画不同步。

新装默认开启 MPV 兼容模式。覆盖升级会保留之前的设置；如果曾手动关闭，请到播放器设置中重新开启。

## 用电视遥控器搜索

1. 打开“搜索”页，选择直播平台和搜索类型。
2. 用遥控器确认输入框，调出电视输入法，输入关键词。
3. 选择输入法的“完成”（DONE）或提交键，进入搜索结果，再选择直播间播放。

斗鱼、B 站可按关键词搜索。**抖音请选择“直播间”**，上游目前不支持“主播”搜索。本轮抖音关键词搜索返回空列表，尚未验证通过；此前已验证可从热门、收藏进入抖音直播播放。

第三版已修复 Android 5 搜索页因原生输入框显示方式不兼容而黑屏的问题，已在这台电视上完成输入 `998`、提交、显示斗鱼结果并进入直播的验证。

## 用手机网页输入

手机与电视连接同一局域网，先在电视“搜索”页选择平台和“主播 / 直播间”，再扫描页面二维码进入网页；以电视当时显示的地址为准。在网页选择相应的搜索类型、输入关键词并发送。相关页面会启动所需服务；端口可能自动变化，离开后如无法连接，请重新打开搜索页并扫描最新二维码。

已通过浏览器手机界面发送 B 站关键词“凉哈皮”，电视成功显示结果。本次验证覆盖网页搜索推送，未逐项验收全部手机遥控功能。

## 升级与数据

兼容版使用独立包名，可与上游旧版并行安装。本次原先安装的旧版已按机主要求卸载，未备份其数据。

后续兼容版使用同一固定签名，直接覆盖安装可保留新兼容版的收藏和设置。应用内更新只读取本分叉带 `android5` 标签、与系统架构匹配的兼容安装包。

本版继续作为预览版，尚未宣称完全消除轻微掉帧或通过长时间稳定性验收。已完成项目、安装包校验值和待完成验证见发布页的 [验证报告](#android-5-兼容版验证报告)。

## 播放限制与设置

- 第一版的默认 MPV、IJK 均曾出现明显卡顿和音画不同步。第二版起默认开启 MPV 兼容模式，IJK 关闭未使用的截图 GLES 路径；第三版保留这些设置。
- MPV 兼容模式已确认采用 H.264 / MediaCodec 硬解。一次连续统计中源帧率与输出帧率均为 30，解码丢帧为 0，输出丢帧计数为 1 且未增长；音画差值很小。机主仍能察觉轻微掉帧，因此不凭计数宣称完全流畅。
- 正式发布包的 60fps 抖音直播测试中，输出丢帧计数仍持续增长；活动音轨及画面可用，不能据此标为无掉帧或全场景流畅。
- 电视逻辑输出为 1920×1080 / 60Hz。30fps 内容约 33.3ms 的平均帧间隔正常；已观察到的呈现间隔变化不能单独证明问题来自解码、Flutter 或直播源。考虑到旧版也有类似表现，本次未继续盲改渲染或原生播放器参数。
- 可关闭弹幕、优先 720P 降低负荷；这些设置未在本电视上完全消除轻微掉帧。IJK 可保留作备用，但当前不同步问题仍在。
